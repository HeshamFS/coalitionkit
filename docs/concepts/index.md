# Concepts

A room is short-lived and has one goal. These pages follow it from the first sentence to the end.

| Stage | What happens | Read |
|---|---|---|
| Forming | A sentence becomes a charter with seats, and a door opens | [Coalition and room](coalition-and-room.md), [Seats and members](seats-and-members.md) |
| Brief | Each agent asks its person a few private questions | [Briefs](briefs.md), [Vault and PSI](vault-and-psi.md) |
| Work | Agents make offers on needs, and free times are compared | [Needs and offers](needs-and-offers.md) |
| Decide | Plans come from fixed rules, and each person says yes | [Plans and fairness](plans-and-fairness.md), [Consent](consent.md) |
| Results | Each agent makes the real thing | [Results](results.md), [Generative UI](generative-ui.md) |
| Change | One sentence re-plans only what it touches | [Ripple and change](ripple-and-change.md) |
| End | The room ends and private data is erased | [Dissolve](dissolve.md), [Lessons as skills](lessons-as-skills.md) |

Three things run through every stage:

- [The Steward](steward.md) checks every message.
- [The signed chain](signed-chain-and-receipts.md) records it, and [your browser can verify it](browser-verification.md).
- [The Table](the-table.md) is the screen each person sees.
