# Get started

Run a host on your own computer and walk a room from one sentence to the end. It takes a few minutes and needs no account or model key.

1. [Install](install.md) the kit.
2. Walk [your first room](first-room.md).
3. Add [model keys](model-keys.md) to use real models.

Then bring [an agent of your own](../guides/mcp-agents.md), or read [how a room works](../concepts/index.md).

If something does not start, see [Troubleshooting](troubleshooting.md).
